Dynamic Shopping list
A summary paragraph will keep the user informed of what is currently in the list.
What should happen when a user types an item and clicks the button or pressesEnter:
•The item appears in the list.
•The array is updated to include the new item
•A Delete button is added next to the item—clicking it removes the item from both the list and the array
•The summary updates to reflect the current state of the array •The input is cleared and refocused,ready for the next entry
If the user enters an empty, it should not be added to their shopping list and they should be informed to enter a valid text
